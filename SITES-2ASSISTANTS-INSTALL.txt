AssetGuard — Sites: 2 assistants for the Security company (+ app parity)
========================================================================

WHAT CHANGED
------------
Under Sites, the Security company now carries a Manager + TWO Assistant
managers (was one), inherited read-only from the company record — matching the
client company block. This ships for the WEB and the MAIN Android app.

WEB  (zip: sites-2assistants-web.zip)  — supersedes company-contacts-phase2.zip
  - Add Site → Security company details: pick the security company from the
    dropdown; Manager + Assistant manager 1 + Assistant manager 2 fill in
    read-only (inherited). No regional tier.
  - View Site: shows SECURITY MANAGER, SECURITY ASSISTANT 1, SECURITY ASSISTANT 2.
  - Save writes securityCompany.country = { operationsManager, assistant,
    assistant2 }.
  Files:
    app/mainapp/admin/companies/components/CompaniesAdmin.jsx
    app/api/apiUtils/dataControl/companies.js
    app/mainapp/admin/settings/components/SystemSettings.jsx
    app/api/apiUtils/dataControl/siteContacts.js
    app/api/mainapp/site-contacts/route.js
    app/api/mainapp/companies/directory/route.js
    app/mainapp/sites/components/AddSite.jsx
    app/mainapp/sites/[id]/components/ViewSite.jsx

  Deploy (web):
    cd /var/www/html/baseapps/assetguard
    python3 -c "import zipfile; zipfile.ZipFile('sites-2assistants-web.zip').extractall('.')"
    npm run build
    pm2 restart gps-3000 assetguard-3010
  (No DB migration — the companies.contacts column came in Phase 1. If you
   never applied Phase 1, run db/company_contacts.sql first.)

MAIN ANDROID APP  (zip: sites-2assistants-mainapp.zip)  — package com.example.assetguard
  - Add Site: client company block is now read-only inherited; Security company
    is a dropdown of registered security companies; its Manager + 2 Assistants
    fill read-only. Regional tier removed. Monitoring company is a dropdown.
    Now calls GET mainapp/companies/directory (new) instead of the old
    region-based mainapp/site-contacts staff lookup.
  - View Site: adds SECURITY MANAGER / SECURITY ASSISTANT 1 / SECURITY
    ASSISTANT 2 to the details grid.
  Files (unzip into the Assetguard project root, preserving paths):
    app/src/main/java/com/example/assetguard/utils/ApiRoutes.kt
    app/src/main/java/com/example/assetguard/models/SiteContacts.kt
    app/src/main/java/com/example/assetguard/models/Site.kt
    app/src/main/java/com/example/assetguard/ui/sites/add/AddSiteViewModel.kt
    app/src/main/java/com/example/assetguard/ui/sites/add/AddSiteScreen.kt
    app/src/main/java/com/example/assetguard/ui/sites/add/AddSiteFields.kt
    app/src/main/java/com/example/assetguard/ui/sites/view/ViewSiteScreen.kt
  Then rebuild the app (./gradlew assembleRelease or Android Studio).
